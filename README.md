# Slay - Multi-Tenant Appointment & Booking SaaS

Slay is a multi-tenant appointment booking platform for service businesses such as salons and barbershops.

Each business has its own services, providers, clients, working hours and bookings, with tenant isolation enforced using Supabase Row Level Security.

## Features

- Multi-tenant business management
- Supabase authentication
- Public booking pages
- Service and provider selection
- Availability based on business hours, service duration and existing bookings
- Blocked periods
- Double-booking protection
- Booking status management
- Client management / CRM
- Tenant-level data isolation using RLS
- Responsive React frontend

## Tech Stack

- React + Vite
- JavaScript
- CSS
- Supabase
- PostgreSQL
- Supabase Auth
- PostgreSQL RPC functions
- Row Level Security
- Vercel
